إصلاح التمرير العام
- تم تعديل CSS في index.html للسماح بتمرير الصفحة الرئيسية وجميع الصفحات رأسيًا حتى تظهر الأيقونات الموجودة أسفل الشاشة.
- تم إبقاء مناطق التمرير الداخلية للمصحف وقوائم القراء كما هي.
- لم يتم حذف ملفات أو تغيير ترتيب الأيقونات أو محتوى الخدمات.
- عند النشر، ارفع محتويات هذا الأرشيف كاملة بدل النسخة السابقة، ثم أعد تحميل الموقع تحديثًا قويًا/امسح ذاكرة التخزين المؤقت إذا بقي التصميم القديم.
